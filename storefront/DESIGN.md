## Visual system
Active tokens and components are in src/theme.css, layered over retained structural primitives in src/style.css. Canvas/paper #f4f4f4, ink #090909, secondary #727272, line #dbdbdb, lime #dcff75. A black full-width pricing band uses #090909 and #131313 cards, with the middle card white. No arbitrary gradients except the deliberately glossy sticker surfaces taken from the selected reference's visual language. Fonts follow the Dovv reference and are locally bundled (OFL, latin + latin-ext for Azerbaijani): Archivo 900 as StudioHeadline (hero, card titles, wordmark, contact statement; the face is declared at weight 900 only, so every display rule renders black), Inter as StudioSans (text, controls, section headings), Geist as StudioNumeric (prices, totals) and DM Mono as StudioMono (small labels). Declarations are in src/fonts.css, licenses in public/assets/fonts. No external font requests. Archivo is much wider than the earlier Anton, so hero, process-card and pricing-card headings have per-breakpoint sizes in studio-polish.css.

## Languages — 29 October 2026
The site ships in Azerbaijani (source), Russian and English at /az/, /ru/ and /en/ (index, catalogue.html, product.html in each). The root URLs stay Azerbaijani and declare /az/ as canonical. Copy lives in Azerbaijani in the HTML and JS; storefront/src/i18n/strings.js maps each Azerbaijani string to [ru, en]. Runtime strings go through t() / href() in src/i18n.js; scripts/i18n-pages.mjs runs after the Vite build, translates every text node and aria/alt/placeholder/meta attribute, prefixes in-site links, writes hreflang/canonical/og:locale and fails the build when a non-ASCII string has no translation. tests/i18n.test.mjs checks placeholders, duplicates and data coverage. Cyrillic falls back from Archivo (no Cyrillic) to Inter 900 for display text. The language switcher is a .lang-switch nav in headers and footers and keeps the product query string. Prices, option rates and the WhatsApp number are identical in all languages; the WhatsApp draft is written in the visitor's language.

Pricing cards, the project dialog and service pages link between all three layers.
