How every result is decided

All shuffles, wheel spins and slot spins happen on the BAKHY game server. Before a hand starts, the server picks a secret server seed and shows you only its SHA-256 fingerprint. Your browser adds its own random client seed. Every random number is HMAC-SHA256(server seed, client seed : counter).

When the hand ends the server seed is revealed. This page re-deals the hand in your browser from the revealed seeds and the move log, and checks that it matches the fingerprint you saw before the hand and the table the server ended with. Nobody, including the site owner, can change a deal after the fingerprint is shown without this check failing.
