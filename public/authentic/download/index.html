Authentic for Mac and Windows

Offline.
On your desk.

The same detector as the website, running on your computer. Drop a whole stack of assignments. Nothing is uploaded.

Download for MacmacOS 11+ · Apple silicon and Intel · 3.9 MB Download for WindowsWindows 10 and 11 · 64-bit · 1.9 MB

Version 1.0.0 · Model 2026.10-v2 · Free during beta

Install in a minute.

Mac

Open the zip. Drag to Applications.

The first time, right-click Authentic and choose Open, then Open again. macOS asks once because the app isn’t notarized yet.

Windows

Run the installer. No admin needed.

If SmartScreen appears, choose More info then Run anyway. Authentic installs for your user and adds Start menu and desktop shortcuts.

Batch

Many files at once.

Drop a stack of essays. Each gets its own report in the library.

Private

Nothing leaves your computer.

No account, no upload, no internet needed after download.

Same engine

28,531 documents of training.

Identical model and calibrated ranges as the website.

Authentic reports probabilities, not proof. Never use a result as the only basis for an academic decision.

Accuracy figures are measured on 12,554 held-out documents for model 2026.10-v2. See Accuracy for the method and known limits.
