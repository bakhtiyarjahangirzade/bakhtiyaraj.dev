Paragraph scores

Every paragraph, its own score.

Text is split into 50–220 word paragraphs and highlighted, so mixed essays are easy to discuss.

Adaptive range

A reference range with a stated scope.

The reference band was calibrated on synthetic essay mixtures. It is not a confidence guarantee for an individual student document.

Clear verdicts

Or a clear “we don’t know”.

Human-like signals, AI-like signals, or uncertainty. Ambiguous scores do not establish mixed human and AI authorship.

Model card

28,602 documents. 13 AI models.

Every report shows the model version and how it was tested.

Trace scanner

Tricks leave fingerprints.

Each finding is rated, so an innocent character never weighs as much as a hidden instruction.
