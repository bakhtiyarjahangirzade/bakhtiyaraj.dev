# BAKHY design direction

Personal developer content hub; the page leads visitors to real source code.
Turkish is the initial content language. No account, form, or backend behavior.

## Visual language

Cool blue workspace with generous spacing; a large typographic thesis and a small
idea → build → share strip express the development loop. Avoid fake project counts,
testimonials, invented work, decorative dashboards, and external font dependencies.

## Runtime tokens

`public/styles.css` is the single token owner. Paper #f5f7fc, ink #17243f,
muted #47536b, brand #243a73, accent #c5d2f1, line #c6cede.
Display: Arial Black / Segoe UI. Body: Segoe UI / Arial. Utility: Consolas.
Use native anchors, visible focus, one document scroller, and responsive stacked sections.
There is no animation; reduced-motion users receive the same stable page.
