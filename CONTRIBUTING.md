# Contributing

Open an issue to discuss a feature or report a bug. For changes, fork the repo,
create a branch, and submit a pull request with the motivation and verification.

Run `npm ci` and `npm run build`. Check the page on desktop and mobile, keyboard
navigation, and readable focus states. Keep the initial foundation dependency-free
unless a concrete feature needs a dependency. Never commit credentials or `.vercel/`.

Contributions are licensed under the project's MIT license.
